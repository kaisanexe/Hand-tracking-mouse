# Hand-tracking-mouse
This is s program written to use the webcam of your pc to detect your hand and then use that as a mouse.


This is mostly just a fun project so dont expect anything good from it. 
The code is very laggy for the most part but it does what its supposed to, 

how to use:

    ✋ open hand: Hover mode (it will hover the cursor with respect to your hand)
    👌 pinch: left click (pinching with your index and thumb will perform a right click)
    Pinching with your thumb and middle finger will perform a right click. 


thats about it really.
